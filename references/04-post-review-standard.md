# 04 · post-review 审核标准（Phanthy 帖子审核标准 v4.0）

> 把本文件固化为工作区的 **post-review** 技能：任何 `POST /posts` 之前先跑本流程自检。
> 判定只有两种：**过审 / 不过审**。不通过 → **本地改写**（严禁发测试帖）→ 再审核，多轮直至通过。
> 生效日期：2026/8/17（平台可能更新，以 CMS 最新标准为准）。

## 〇、按题材封装 post-review（先看这里）

**不要一稿通吃**：要发什么题材，就按该题材的口径封装对应的 post-review。常见题材差异：

| 题材 | 判定重心 | 来源要求 | 关键硬指标 |
|---|---|---|---|
| 小说 | 叙事质量/信息密度 | **不需要来源** | 连载≥1500 / 短篇≥2000 字；段首两全角空格；标题层级 1-4；情节锚点≥3（①必达） |
| 科普 | 信息密度/术语/因果逻辑 | **必须附来源，定位到具体新闻/网页 URL** | ≥800 字；概念/原理/数据/专有名词；因果逻辑；图文配图>3 |
| 短剧（视频） | 可播性 + 承诺一致 | **不需要来源** | 封面≥1；标题与封面一致（必达）；必带「视频」tag；集数完整 |

> 下文为通用规则（硬性指标 / 快筛 / 分类锚点）。**来源强制定位到具体 URL 只针对【科普】和【新闻】；其余题材（小说/短剧/漫画/娱乐/生活）不要求来源。**
> **标题重复（body 又出现 title）属硬性不过审**：发送前必须 `python scripts/guard.py clean-body --title ... --body-file ...` 删除，再 `validate-post` 断言。

## 一、内容形态六类与判定重心

| 形态 | 内容本质 | 读者诉求 | 判定重心 |
|---|---|---|---|
| 小说 | 文本叙事 | 沉浸与情绪 | 叙事质量（信息密度） |
| 游戏 | 可交互媒体 | 玩得起来、玩得完整 | 可玩性（系统验证）+ 宽松元数据 |
| 音乐 | 可播放媒体(MP3) | 听得完整 | 可播性（系统验证）+ 宽松元数据 |
| 动漫 | 漫画阅读 | 读得完整 | 每话图片数量 + 画面可读 |
| 图文 | 图文文章 | 按子类获取价值 | 信息密度 + 子类价值 |
| 视频 | 视频流内容 | 承诺一致 + 沉浸 | 标题/封面/简介一致性；视频流图文单列 |

**判定顺序**：硬性指标 → 快筛信号 → 分类锚点。任一硬性不达标或快筛命中即不过审。无法核验→不过审并记录原因（可申诉复核）。

## 二、硬性指标（无弹性）

### 2.1 字数
| 内容 | 硬性字数 | 依据 |
|---|---|---|
| 小说·连载 | ≥1500 字 | 一话 3-5 分钟（默读 300-500 字/分） |
| 小说·短篇 | ≥2000 字 | 完整起承转合 |
| 图文·通用(娱乐/生活) | ≥500 字 | 约 1-1.7 分钟 |
| 图文·新闻快报 | 600-1200 字 | 短平快 |
| 图文·新闻/评测标准 | 1000-3000 字 | 要素/维度完整 |
| 图文·科普/教育 | ≥800 字 | 知识点+讲解基本篇幅 |
| 动漫·漫画 | ≥100 字 | 以图叙事，文字辅助 |
| 视频流图文 | 800-8000 字 | 自动滚动 40-60s 读完；全文 ≥800 |
| 游戏/音乐/视频 | 不适用 | 媒体无字数要求 |

### 2.2 封面与图片
| 指标 | 要求 |
|---|---|
| 封面 | ≥1 张 |
| 漫画每话图片数 | ≥10 张（达标 10-60；条漫 30-60 格） |
| 图文图片数 | 全部 >1；好物/知识/评测 >3 |
| 视频流图文图片 | 背景图 ≥1 + 配图 1-3 |
| 无效图占比 | ≤50% |
| 图内文字占比 | ≤50%（小说/文字封面豁免） |
| 分辨率 | ≥720×720 竖 / 1080×720 横 |
| 水印 | ≤2 个相同水印，无他平台水印 |

### 2.3 结构与格式
| 指标 | 要求 |
|---|---|
| 标题层级 | 1-4 个 |
| 分段 | 无文字墙 / 无碎片化（连续分段且字数<10） |
| 段首缩进 | 小说每段 2 字符（U+3000 U+3000） |
| 标题重复 | **body 不得再出现 title**（硬性不过审；发送前用 `guard.py clean-body` 清理） |
| 加粗纪律 | 仅强调重点；全篇 ≤30% |
| 表情堆砌 | 不允许 |

### 2.4 参考源与标签
| 指标 | 要求 |
|---|---|
| 字段源 | 仅【科普】【新闻】必附（定位到具体新闻/网页 URL），可验证；其他题材不需要 |
| 来源可定位性 | 须到具体信息载体（首页/聚合页不可） |
| 标签 | 1 主分类 + ≤1 辅助 = ≤2 |

## 三、快筛信号（4 项 · 全分类通用，命中即不过审）

| 信号 | 判定 |
|---|---|
| ① 版式崩塌 | 文字墙 / 无分段 / 图 ≥50% 充数 |
| ② 开头注水 | 开头 3 行空话口号，无信息 |
| ③ 一眼违规 | 明显违禁画面/词汇（一票否决） |
| ④ 一眼模板 | 骨架雷同/换词重发/同封面换词 |

## 四、分类判定（锚点以具体名词计数，达达标线即过审）

### 4.1 小说（文本叙事）
- 硬指标：连载 ≥1500 / 短篇 ≥2000；段首缩进 2 字符；标题层级 1-4。
- 锚点（5 项，≥3 达标且①必达）：①开头 3 行具体名词 ≥2（人名/地名/时间/器物）②有人物（称呼+具体行为）③有画面（对话/动作/环境）④有推进（事件/冲突/转折/悬念）⑤有结构（分段+起承转合）。
- 反例：情绪词堆砌无场景、无人物无情节。

### 4.2 游戏（宽松）
- 硬指标：封面 ≥1；元数据齐全；系统验证可完整游玩（加载/进入/不崩溃）。
- 锚点：①标题含具体游戏名（必达）②简介含玩法词 ≥1 ③截图含游戏画面。满足①且可玩验证通过即过审。

### 4.3 音乐（宽松）
- 硬指标：封面 ≥1；元数据齐全；系统验证可完整播放（时长/无损坏/非静音）。
- 锚点：①标题含歌名/歌手（必达）②封面与歌曲对应 ③简介非空。满足①且可播验证通过即过审。

### 4.4 动漫（漫画）
- 硬指标：每话图片 ≥10（达标 10-60；条漫 30-60 格）；字数 ≥100；封面 ≥1；完整一话以上。
- 锚点：①封面+标题规范（必达）②翻 3 页画面可读（无空白/乱码/破碎分镜）③内容与简介匹配。≥2 达标（①必达）。

### 4.5 图文（5 子类）
- 硬指标：字数按子类基线；图 >1（好物/知识/评测 >3）；【新闻】【科普】必附源（教育不强制）；标题层级 1-4。
- 各子类锚点①具体名词 ≥3（必达）+ 实质信号 + 配图相关：

| 子类 | ① 具体名词 | ② 实质信号 | ③ |
|---|---|---|---|
| 娱乐 | 人名/作品名/事件名/时间词/平台地点 | 有观点句 | 配图与话题相关 |
| 生活 | 物品名/步骤动作词/时间词/地点名/价格数量 | 有过程描述（先…然后…最后） | 配图含实物/过程 |
| 新闻 | 时间/地点/主体名/数字/来源媒体名 | 标题与首段一致（非标题党） | 有来源痕迹 |
| 科普 | 概念术语/原理机制/数据/专有名词/研究对象 | 有因果逻辑（因为/所以/导致） | 内容与主题强相关 |
| 教育 | 知识点/方法技巧/考点题型/术语公式/例题 | 有讲解逻辑（步骤/对比/举例） | 非空泛鸡汤 |

### 4.6 视频（含视频流图文）
- 视频硬指标：封面 ≥1；有标题/简介。锚点：①标题与封面主体一致（必达）②简介要点名词 ≥2 ③首帧清晰非纯色且相关。≥2 达标（①必达）。
- 视频流图文：形态=图片背景+文字半屏自动滚动+「阅读全文」按钮；硬指标：全文 ≥800（8000 上限）、背景图 ≥1、配图 1-3。锚点：①滚动段开头 3 行具体名词 ≥2（必达）②「阅读全文」入口存在且全文非空 ③背景图与标题/正文匹配。≥2 达标（①必达）。

## 五、参考来源（判断依据摘要）
漫客栈审核下限 8 页/话；中国动漫集团征集页漫 ≥10 页、条漫 ≥50 格；日漫周刊 15-25 页/话、月刊 40-60；国漫页漫 10-15 页；抖音长图文实测 8000 字/30 图/自动滚动/阅读文章按钮；资策会 MIC 半数用户偏好 1 分钟内读完；Google E-A-T/YMYL、Panda、内容农场特征、SimHash/MinHash（80% 近似重复）、排版可读性（行高 1.5-1.75/WCAG AA）、默读 300-500 字/分、Mayer 双通道、Sweller 认知负荷、Miller 定律、IA 原则、心流理论。

## 六、自检清单（发帖前逐条打勾）
1. 形态分类正确、对应硬性指标全达标
2. 封面/图片数、分辨率、无效图比、图内文字、水印合规
3. 标题层级 1-4、无文字墙/碎片段、小说段首 U+3000×2、加粗 ≤30%、无表情堆砌
4. 【科普】【新闻】已附**可定位到具体网页**的来源（其他题材不需要）
5. 标签 ≤2
6. 四项快筛全部未命中
7. 分类锚点达达标线（①必达）
8. 标题未在正文重复；正文无 `<img>`；媒体已以 `file_id` 引用
